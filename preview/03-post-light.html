Claude API로 나만의 AI 글쓰기 어시스턴트 만들기

Anthropic의 Claude API를 이용하면 강력한 AI 기능을 손쉽게 내 서비스에 녹여낼 수 있습니다. 이번 글에서는 개인화된 글쓰기 어시스턴트를 처음부터 만들어보겠습니다. 프롬프트 캐싱으로 비용을 절감하고, 스트리밍으로 사용자 경험을 끌어올리는 방법까지 모두 담았습니다.

시작하기 전에

Claude API를 사용하려면 몇 가지 사전 준비가 필요합니다. 이 섹션에서는 개발 환경 설정부터 API 키 발급까지 차근차근 살펴보겠습니다.

개발 환경 준비

이 프로젝트는 Python 3.10+ 또는 Node.js 18+에서 동작합니다. 아래 두 가지 방법 중 편한 것을 선택하세요.

  • Python: anthropic 패키지 설치
  • Node.js: @anthropic-ai/sdk 패키지 설치
  • API 키 발급 후 환경변수 ANTHROPIC_API_KEY 설정

API 키 발급

Anthropic Console에서 계정을 생성하고 API 키를 발급받으세요. 키는 외부에 노출되지 않도록 반드시 .env 파일에 보관하고 .gitignore에 추가해야 합니다.

보안 팁: API 키는 절대 코드에 하드코딩하지 마세요. 환경변수나 시크릿 매니저를 사용하는 것이 원칙입니다.

Claude API 기본 사용법

SDK를 설치했다면 이제 첫 번째 요청을 보내볼 차례입니다. Messages API의 기본 구조를 이해하면 이후 모든 활용이 쉬워집니다.

Python SDK로 첫 요청 보내기

import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[
        {
            "role": "user",
            "content": "블로그 포스트 초안을 작성해주세요."
        }
    ]
)

print(message.content[0].text)

시스템 프롬프트 설정

글쓰기 어시스턴트의 성격과 규칙을 정의하는 시스템 프롬프트가 핵심입니다. 아래와 같이 설정하면 일관된 문체로 글을 생성할 수 있습니다.

파라미터 설명 권장 값
model 사용할 Claude 모델 ID claude-sonnet-4-6
max_tokens 최대 응답 토큰 수 4096 (장문 생성 시)
temperature 창의성 조절 (0~1) 0.7 (균형)

프롬프트 캐싱으로 비용 절감

Prompt Caching은 시스템 프롬프트처럼 반복적으로 사용되는 내용을 캐시에 저장해 API 비용을 최대 90%까지 줄여주는 기능입니다.

캐싱 적용 방법

message = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    system=[
        {
            "type": "text",
            "text": "당신은 전문 블로그 작가입니다...",
            "cache_control": {"type": "ephemeral"}  # 캐싱 적용
        }
    ],
    messages=[{"role": "user", "content": user_input}]
)

스트리밍으로 UX 개선

긴 글을 생성할 때 응답이 완전히 완성될 때까지 사용자를 기다리게 하면 불편합니다. 스트리밍을 활용하면 토큰이 생성되는 즉시 화면에 표시할 수 있습니다.

스트리밍 구현

with client.messages.stream(
    model="claude-sonnet-4-6",
    max_tokens=2048,
    messages=[{"role": "user", "content": prompt}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
